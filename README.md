# ai-hub

PC에서 하는 모든 작업을 Obsidian 볼트에 기록하고, 여러 AI가 같은 기억을 검색해 쓰게 하는 개인 기억 시스템.

- 수집기: 원천(프로젝트 문서·커밋·AI 대화)을 주기적으로 훑어 볼트에 1차 정제 기록
- 마스킹 Git 필터: 볼트를 GitHub에 올릴 때 민감한 이름을 가림
- 검색 엔진·기억 서버: 한국어 하이브리드 검색(BM25 + 벡터)과 MCP

설정과 원장은 `~/.ai-hub/`에 있고 이 저장소에는 넣지 않는다. AI 작업 규칙은 `AGENTS.md`.

## 외부 대상의 격리 시험

내장 ai-hub 이외의 대상은 `repos.toml`의 해당 `[[repo]]`에 `isolated_inputs`를 지정해야 자동 시험을 실행한다. 이 목록은 사용자가 허용한 소스와 합성 시험 자료의 정확한 상대 파일 경로다. 원고·운영 DB·계정 자료를 넣지 않는다. 경로를 지정하지 않으면 시험은 미실행·미검증으로 남는다.

```toml
isolated_inputs = ["src/logic.py", "tests/test_logic.py", "tests/fixtures/synthetic.json"]
```

- 디렉터리·글롭·상위 경로·심볼릭 링크·하드링크·Git 객체는 입력으로 사용할 수 없다.
- 등록된 Python unittest 명령을 복사된 입력과 런타임으로 실행하며 원본 홈·대상 저장소·네트워크·브라우저·자식 프로세스 접근을 차단한다. 현재 macOS Homebrew Python 배치만 지원한다.
- 코드 작성·검토 AI에는 목록의 내용만 제공하고 도구 호출은 제한한다. 수정은 목록과 요청서의 `owned_paths` 양쪽에 있는 파일만 받는다.
- 외부 대상에서 실행 가능한 커밋 훅, 파일 변환 필터, 외부 병합 드라이버, 파일 감시 또는 커밋 서명 설정이 있으면 격리 밖 실행을 피하려고 중단한다. 검사를 우회하지 않는다.
- 시험 결과는 실행·실패·오류·건너뜀 수를 보존한다. 목록 밖 자료나 지원하지 않는 의존성이 필요하면 성공으로 대체하지 않는다. 합성 부분 시험 결과는 저장소 전체 시험의 성공을 뜻하지 않는다.
